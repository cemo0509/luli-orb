## 14.2 为什么选 1.43：**窗口压边**这一条就足够决定

遮光盖中心要开一个窗，窗口必须满足两个条件：

```
屏直径  <  窗口直径  <  板直径
（不挡显示）        （压住板边，不露出 PCB）
```

| 方案 | 屏 | 窗口 | 板 | **压边余量** |
|---|---|---|---|---|
| 1.43C | Ø36.75 | Ø39 | Ø46.0 | **单边 3.5mm** ✅ |
| 1.75-B | Ø44.4 | Ø50 | Ø51.2 | **单边 0.6mm** ⚠️ |

1.75 那个 0.6mm，意味着：

- 打印件公差 ±0.2、玻璃贴合偏差 ±0.1、屏幕本身公差 ±0.1 → 三项叠加就把余量吃完了
- 一旦超差，窗口边缘会**露出一圈 PCB**（绿/黑板的边），正面看就是"黑面上有个亮环"
- 而这个产品最不能出的问题就是"屏边可见"

**1.43 的 3.5mm 压边，把这条路彻底堵死。**

## 14.3 另外三条加分

1. **像素密度高 19%**（316 vs 266 ppi）：眼睛 178px 高 vs 147px，玻璃后看边缘更干净
2. **板小 5mm**：机身可以从 Ø58 收到 Ø56，在 Ø70 的球下更协调
3. **便宜 ¥30~35**

代价：小智固件支持要确认一次（见 14.6）。**这个风险可控**——最坏情况用通用 `esp32-s3-dev` 配置 + 自定义引脚，微雪的 ESP-IDF 例程是齐的。

## 14.8 一句话总结

**选 1.43 不是因为它更好看，是因为 1.75 的窗口只剩 0.6mm 压边——一个打印公差就能让 PCB 露出来。**
在这个产品里，"屏边可见"是死刑，其他都是次要的。

## 14.9 结构改版：后半球一体机身

> 定稿后追加。原方案是「玻璃半球 + Ø56 圆柱机身」，改成 **「玻璃半球 + 打印后半球」**，
> 两个半球合成一整颗 Ø70 球。零件数从 5 件降到 **2 件**。

### 14.9.1 新的两件套

| # | 件 | 材料 | 作用 |
|---|---|---|---|
| 1 | 玻璃半球 Ø70 | 实心亚克力（已有） | 前脸：透明、成像 |
| 2 | **打印后半球 Ø70** | 黑色 PETG / PLA | 后脸 + 遮光面 + 容腔 + 出声孔 |

后半球一件顶四件：外观、遮光板、机身、喇叭箱。原来的「遮光盖 + 机身 + 底盖」全部并进去了。

### 14.9.2 实测尺寸（`hardware/rear_shell.scad`）

| 项 | 值 |
|---|---|
| 外径 | Ø70（与玻璃半球一致） |
| 高度 | **33.5**（球顶被 Ø20 喇叭孔截掉一截，不是 35） |
| 壁厚 / 赤道板厚 | 2.5 |
| 中心窗 | Ø39（1.43 屏 Ø36.75，压边 1.1）+ 内侧 1.2 陷光倒角 |
| 喇叭腔 | Ø30 深 9 → Ø20 出声孔 |
| Type-C 孔 | 11 × 4.5，赤道板上方 5mm |
| 主板定位环 | Ø47.8 / 内 Ø46.2，高 1.2 |
| **体积** | **22.3 cm³**（STL 实测，不是估算） |
| **重量** | PLA **≈28 g** / PETG ≈28 g |

> 内腔体积：半球内腔 = (2/3)π·32.5³ ≈ **71.9 cm³**。
> 装 板 17 + 电池 20 + 喇叭 15 = 52 cm³，余 **20 cm³** 走线——很宽松。

### 14.9.3 三个必须解决的问题

| # | 问题 | 解法 |
|---|---|---|
| 1 | **重心后移** | 全部重量（板/电池/喇叭）都在后半，综合重心在球心后方约 8~12mm，球会往后倒。**底座必须做凹球面托座（SR35，深 10~12mm）**，把球托住 |
| 2 | **玻璃不能打孔** | 两个半球在赤道面对接，接触面是 **Ø70 全平面 = 38.5 cm²**。用 VHB 双面胶或 UV 胶粘住，抗剪强度远超自重（<300g） |
| 3 | **喇叭朝后** | Ø20 孔开在球顶，声音朝后射。如果放在桌面上，后向声会被墙面反射，可能闷。**打出来先试听**，不行就改侧向或加导声槽 |

### 14.9.4 打印要点

- **朝向**：赤道平面朝下贴床，穹顶朝上（像一个倒扣的碗）。第一层是 Ø70 的环，接触面积大、不翘边
- **支撑**：内腔靠近球顶处是"天花板"，**需要树状支撑**（只在内部）。拆完内壁会略粗糙——反正要喷哑光黑，无所谓
- **材料**：黑色 PETG 优先；PLA 也够（球内温度不高）
- **后处理**：内腔喷哑光黑（关键，决定"真空黑"成立不成立）
