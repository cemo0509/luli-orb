## 4.2 主控（已有，不重买）

**微雪 ESP32-S3-Touch-AMOLED-1.75-B，SKU 31262，¥209，Ø51.00×12.10（板体 11.70）**

| 项 | 值 | 对本项目意味着 |
|---|---|---|
| SoC | ESP32-S3R8，双核 LX7 240MHz | 跑小智固件够用 |
| 内存 | 8MB PSRAM + 16MB Flash | ✅ 满足小智硬性要求（Flash≥16MB、PSRAM≥4MB） |
| 屏 | 1.75" AMOLED 466×466，CO5300，QSPI | 主角，266ppi |
| 触摸 | CST9217 电容触摸 | 可做"摸头/戳眼"交互 |
| 音频 | ES7210 ADC + 双麦阵列 + ES8311 codec | 唤醒/降噪 |
| 电源 | AXP2101，MX1.25 电池口，Type-C | 可直接吃 5V 输入 |
| 传感 | QMI8658 六轴 IMU | 拿起/摇晃/倾倒检测 |
| 时钟 | PCF85063 RTC | 状态栏时间，断电走时 |
| 存储 | micro SD | 表情包/语音缓存 |

> ⚠️ **AXP2101 无电池工况**：本项目电池在底座，球内只有 5V 输入。AXP2101 在只有 VBUS 时会正常给 SYS 供电（等同"边充边用"），但**必须实测确认不会反复进充电检测循环**。若异常，加一颗 300mAh 小电池放球内做缓冲（板上有现成 MX1.25 口）。

## 4.3 屏与眼睛的关系

- 有效显示区 Ø44.4mm，466×466 → **1px = 0.0954mm**
- 眼睛设计尺寸：74×185px（7.0×17.6mm），中心距 248px
- UI 背景必须 `#000000`（见 02 章）
- 亮度：默认 40%，室内可读；环境光 >800lux 时自动到 80%（V1.1 加光感）

## 4.4 音频

| 环节 | 方案 | 理由 |
|---|---|---|
| 拾音 | 板载双麦（球内，靠近顶部内壁） | 离嘴近，拾音好；内胆+球壳需开拾音孔（见 3.8） |
| 播放 | **I2S → 底座 MAX98357A → Φ28 8Ω 2W** | 喇叭腔体在底座（≈60cm³），低频比塞球里好一个量级 |
| 备选 | 板载 ES8311 喇叭焊盘 → 球内 Φ28 喇叭 | 省掉 I2S 走线，但声音闷、球体拿下后仍能响 |

**I2S 并联的可行性**：ESP32-S3 的 I2S 总线可同时挂 ES8311（板载）与 MAX98357（底座），两者都收同一组 BCLK/LRCK/SDIN。固件里不启用 ES8311 的 DAC 输出即可，互不干扰。
> 若调试发现 ES8311 初始化时抢总线，退化方案：只用 ES8311 的 ADC（麦克风），I2S 输出直通 MAX98357。

## 4.6 灯环

- WS2812B 5050 ×16，环形 Ø100，间距 19.6mm
- 导光件：乳白半透亚克力/PC，Ø104×3，把点光源揉成连续光环
- 驱动：ESP32 一路 RMT（GPIO 经 pogo 的 LED_DIN）
- 用途：说话律动（跟音量包络）、思考呼吸、低电量红闪、配网蓝闪
- 电流：16×20mA@全白 = 320mA，实际用 20% 亮度 ≈ 60mA

## 4.8 Wi-Fi 天线（容易翻车，务必先测）

- 板载 PCB 天线在 Ø51 板边缘，被 **Ø99 内胆 + Ø110 亚克力球壳** 两层包住
- 亚克力（PMMA）对 2.4GHz 损耗很小（<0.5dB），**不是问题**
- 真正的问题：**黑色 PETG 常用碳黑色母，碳黑是导电的，会严重衰减 2.4G**

**对策（三选一，按顺序试）**：

1. 内胆用**白色/本色 PETG** 打印，外表面喷哑光黑漆（漆层薄，影响小）
2. 若必须黑色料，选**非碳系黑**（铁黑/有机黑），下单时问清楚
3. 天线正对的那一小块内胆壁（约 30×20mm）做**0.8mm 薄壁**（其他处 2.5mm）

**验收**：装壳前后各测一次 RSSI，衰减必须 **< 5dB**。若 >10dB，直接换料重打。
