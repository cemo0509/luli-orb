# 02 · 光学与显示方案

> 这一章决定"像不像"。结构可以粗糙一点，光学不能错。

## 2.1 三条路线的取舍

| 路线 | 做法 | 眼睛视觉大小 | 成本 | 风险 | 结论 |
|---|---|---|---|---|---|
| **A 黑内胆 + AMOLED 贴窗** | Ø99 黑哑光内胆，1.75" 屏装在前窗后 10mm | 64% 屏径 = 眼占球 16%（与参考一致） | ¥0 增量 | 屏边要靠"黑对黑"隐藏 | ✅ **主线** |
| B A + 平凸透镜放大 | 屏后移 22mm，前加 Φ62 平凸镜 f=60，m≈1.58 | 眼放大到 25% 球径 | +¥40 | 边缘色散、可见"透过放大镜"感、公差敏感 | 备选（想做大眼时） |
| C 实心球当球透镜 | Φ60 实心亚克力球，屏贴在球后 | 强放大 + 球形畸变 | +¥50 | 内部不可维修、光损失大、无法消光 | ❌ 不进主线 |

**为什么 A 就够了**：按 1.2 的归一化测量，参考产品的眼高只占球径 16%，1.75" 屏（Ø44.4）在 Ø110 球里 1:1 使用就正好是 16%。我之前估的"要大屏"是错的，是我看帧时的错觉——被"整块黑面"骗了，其实黑面是内胆，不是屏。

---

## 2.2 为什么必须是 AMOLED（这条不可替换）

| 对比项 | AMOLED（1.75" 466×466） | 圆形 IPS LCD（3.4" 800×800） |
|---|---|---|
| 熄屏黑 | 像素不发光，**0 nit**，物理纯黑 | 背光常亮，黑场 0.3~0.8 nit，呈**灰** |
| 屏边可见性 | 与黑内胆**完全融合**，看不出屏在哪 | 必须做一圈黑框过渡，否则灰屏浮在黑胆上 |
| 侧面漏光 | 无背光，无侧漏 | 背光从屏侧溢出，内胆里会发灰 |
| 视角 | 178°，侧看不变灰 | IPS 侧看发白 |
| 分辨率 | 466px / 44.4mm = **266 ppi** | 800px / 87mm = 234 ppi |
| 价格 | 与主板一体（微雪 1.75-B ¥209 含全部） | 模组 $75~80 起，还要 MIPI 驱动板 |

**一句话**：LCD 的黑是"暗灰"，在这个产品里等于当场破功；AMOLED 不亮的地方就是黑的，屏边不用藏，因为它根本不可见。

---

## 2.3 屏边怎么"消失"——三个必须同时满足的条件

1. **屏内容背景必须是 `#000000`**，不能用 `#0A0A0A`、`#111`。任何一个非零值都会在纯黑内胆上浮出一个圆形灰斑。
2. **内胆内表面黑度要和屏黑接近**：哑光黑喷漆（反射率 3~5%）+ 黑色植绒（反射率 <1%）组合。植绒贴在前窗周围 15mm 环带内，这是最容易被看到的区域。
3. **屏与内胆之间不能有硬阴影线**：屏装在前窗后的**沉台**里，屏边压一圈 0.5mm 黑色 EVA 泡棉，遮住屏的柔性排线（FPC）和侧边。任何一条亮缝都会变成"一个发光的小方块"。

> 实测建议：装配后用手机夜景模式贴着球拍一张黑图，看直方图。暗部有 2% 以上的灰度峰 = 有漏光，回去查 FPC 和屏边。

---

## 2.4 视差：让眼睛"在里面"而不是"贴在上面"

屏面距球壳内表面 **10mm**（球心前 42.0mm，球壳内径 Ø104）。

- 侧向 30° 观察时，眼睛相对球壳轮廓的位移 ≈ 10 × tan30° = **5.8mm**（球径的 5.3%）
- 人眼能察觉的位移阈值约 1~2mm，5.8mm 已经明确产生"深度感"
- 上限：屏退得更远视差更大，但屏会缩小（被前窗遮挡），且内胆前球缺变深、顶部弧缝变明显。10mm 是折中值。

**为什么不能贴死在球壳内壁**：贴死 = 零视差 = 一眼"贴纸"，且球壳内壁的反射会直接打在屏上形成重影。

---

## 2.5 杂光与重影

球壳是双层薄壁（外表面 + 内表面），每层菲涅尔反射约 4%：

```
            环境光 → 外表面反射 4%  ─┐
                    ↓ 透过 92%
                   内表面反射 4% ────┼→ 叠加成"双影"
                    ↓
                 内胆（哑光，吸收）
```

对策（按性价比排序）：

1. **内胆外表面做哑光**（打印件喷哑光黑，磨砂面）——把内表面的 4% 反射打散成漫反射，双影变成整体轻微雾感，几乎看不出。
2. **内胆与球壳保持 2.5mm 间隙**——不要接触。接触会产生接触痕、牛顿环、局部应力纹。
3. **球壳内表面贴光学级 AR 膜**（可选，+¥60）——只有追求"消失感"时再加，DIY 贴膜容易起泡，建议 V1.0 之后。
4. **前窗沉台做"陷光"结构**：窗口内壁做 45° 倒角并涂黑，让斜射光进不去。

## 2.6 亮度与可读性

- 屏典型亮度 600 nit（微雪 1.75 用 CO5300，实测满白约 550~620）
- 经 3mm 亚克力（透光率 92%）+ 表面反射损失，正面有效亮度约 **500 nit**
- 室内桌面照度 200~300 lux，眼睛用 30% 亮度（约 150 nit）就足够清晰
- 白天窗边（1000 lux 以上）需要 70~100% 亮度，功耗会上去（见 04 功耗表）
- **建议 UI 眼睛基础亮度 40%，随环境光自动调节**（板载无光感，可加一颗 GL5516 或用屏下触摸电极测电容变化，V1.1 再说）

## 2.7 眼睛的具体画法（决定"可爱"还是"诡异"）

设计值（来自 `hardware/params.py`）：

| 参数 | 值 |
|---|---|
| 屏幕坐标 | 466×466，圆心 (233,233) |
| 眼形 | 圆角矩形（胶囊），宽 74px × 高 185px，圆角 R37px |
| 眼中心 | 左 (109, 250)、右 (357, 250)（中心距 248px） |
| 颜色 | 主色 `#7FE3F0`（冷青），高光 `#DFFBFF`，外发光 `#2BA9C8` @ 35% |
| 状态栏 | y=18~52，字号 26px，右侧电量条 |

几个让眼睛"活"的细节（比形状更重要）：

1. **发光边缘要软**：胶囊不要硬边，外扩 12px 做 3 层递减 alpha 的模糊（模拟 OLED 在玻璃里的散射），硬边会像 LED 灯珠。
2. **眼内要有渐变**：上亮下暗（`#DFFBFF` → `#5FC8DC`），纯色会显得"塑料"。
3. **微动不可少**：即使 idle 状态，也要有 0.3px 幅度的随机漂移 + 每 4~7s 一次眨眼（120ms 完成）。静止的眼睛会在 10 秒内被判定为"图片"。
4. **瞳孔不要画**：参考产品只有胶囊，没有瞳孔/高光点。加了会变成"卡通"，不加才是"生命体"。
5. **黑背景不能纯平**：留一个 3% 的径向渐变（中心略亮），否则 OLED 黑与内胆黑完全一致时，屏幕边界会因为"太干净"反而暴露。

## 2.8 备选路线 B 的具体参数（想做更大眼时启用）

| 项 | 值 | 备注 |
|---|---|---|
| 透镜 | 平凸 Φ62，焦距 f=60mm，PMMA 或 K9 玻璃 | 凸面朝屏 |
| 物距 d | 22mm | 屏到透镜 |
| 放大率 | m = f/(f−d) = 60/38 = **1.58×** | 眼高 17.6 → 27.8mm（占球径 25%） |
| 有效口径 | 前窗需扩到 **Φ70** | 原 Φ50 会被透镜挡住 |
| 代价 | 边缘 15% 区域色散明显 → 用黑色遮光环把边缘 6mm 全部遮掉，实际视区 Φ50 | 等于白放大一圈，得不偿失 |
| 建议 | 只有当你想做 **Ø120 球 + 大眼**版本时才启用，且用非球面镜 | |

**结论：V1 不做透镜。** 前窗 Φ50、屏 1:1，结构最简单，效果已达标。

## 2.9 光学验收清单

| 检查 | 方法 | 合格 |
|---|---|---|
| 漏光 | 暗室贴球拍黑图，看直方图 | 暗部 ≤3% |
| 屏边不可见 | 正面 500mm 处正视，屏显示全黑 | 看不到圆形边界 |
| 双影 | 侧 30° 打台灯，看眼睛边缘 | 无双轮廓 |
| 视差 | 固定机位，正面 / 侧 30° 各拍一张 | 眼位相对球壳位移 ≥3mm |
| 眼形尺寸 | 显示全亮胶囊，卡尺量球面投影 | 17.6±0.5mm |
| 视角均匀性 | 侧 60° 观察眼颜色 | 不明显偏色 |
