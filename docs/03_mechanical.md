## 3.2 尺寸链（球心为原点，+Z 朝上，+X 朝前）

```
                    ┌── 上盖半球 Ø110（无开孔）
                    │
   X=+55  ───────────┤ 球壳外表面
   X=+52  ───────────┤ 球壳内表面
   X=+49.5 ──────────┤ 内胆外表面   ← 2.5 间隙
   X=+47  ───────────┤ 内胆内腔
   X=+42  ───────────┤ 内胆前切平面 Ø52.4（屏/板贴这里）
   X=+23.5 ──────────┤ 板背面（板厚 12.1）
                    │
        Z=-41.6 ────┴── 下壳底孔 Ø56 边缘 → 落到底座凸台
        Z=-55    ─────  球壳理论最低点（被 Ø56 孔切掉）
```

| 项 | 值 | 说明 |
|---|---|---|
| 球壳 | Ø110 / 3.0 壁 / 内径 Ø104 | 吹塑件公差 ±0.4 |
| 球壳↔内胆 | 2.5 单边 | 容错吹塑公差 + 防牛顿环 |
| 内胆 | Ø99 / 2.5 壁 / 内腔 Ø94 | |
| 前切平面 | Ø52.4 @ X=42 | 必须 ≥ 板 Ø51，留 0.7 单边 |
| 前窗 | Ø47 通孔 | 压住屏边 1.3mm，藏住板边 1.8mm |
| 板 | Ø51 × 12.1 | 微雪 1.75-B |
| 底孔 | Ø56 | 走线 + 出声 + 落座 |
| 底座 | Ø110 × 14，顶面 Ø104 凹球面 SR55 深 4 | |
| 整机 | Ø110 × **116**，约 **505g** | |

> **为什么前切平面必须存在**：内腔是 Ø94 球面，在 X=42 处的截面直径只有 Ø42.2——比屏 Ø44.4 还小。若不做平面，屏根本塞不进去。切平后该处直径 Ø52.4，正好容纳 Ø51 的板。

## 3.3 球壳：怎么做到"看起来是一整颗玻璃"

### 采购

- **吹塑高透亚克力半球**，Ø110，3mm，广东东莞一带现货模具多，¥9~15/个（Ø100 现成模具更便宜，Ø110 可能要加模具费，先问）。
- 关键要求：**全新料**（回收料雾度大、发黄）、**透光率 ≥92%**、**内外表面抛光**、**半球带 1.0mm 搭接止口**。
- 一次买 4 个（2 组），留试错。

### 合缝方案（V1，可拆）

不用胶，做**扭转卡扣**：

- 下壳上沿外翻 1.0mm 止口环；上盖内壁做 3 个 L 形槽（间隔 120°）
- 上盖顺时针转 15° 锁死，反向 15° 打开
- 对缝宽度控制在 **0.15mm 以内**，两条边都做 45° 抛光倒角 → 高光下几乎看不出

### 合缝方案（V1.0 精修，粘死）

- 亚克力专用溶剂（二氯甲烷或氯仿）毛细渗透粘接，24h 固化
- 800 → 1500 → 3000 目水砂纸逐级打磨接缝 → 亚克力抛光膏 + 羊毛轮
- 粘死后不可维修，**只在 V1.0 最终版做**

### 底孔与接口环

- 下壳底部开 **Ø56** 圆孔（孔边距球底理论点 13.4mm）
- 接口环（PETG）外形 Ø60、内孔 Ø40、厚 8，用 UV 胶从内侧粘到孔上
- 环内嵌：6× pogo 弹簧针（2.0mm 间距 3.0mm）+ 4× N35 磁铁 Ø8×3（间隔 90°）
- 环顶面装一块 Ø34 的 **遮光/防尘挡片**（黑色 PC），只留 pogo 过孔

> 底孔朝下、被 Ø110 的底座完全遮住，任何正常视角都看不到。

## 3.4 内胆

### 前壳

- 外球 Ø99，前部 X=42 处切平（切面 Ø52.4）
- 切面上开 Ø47 窗，窗口内壁做 **45°×0.8 倒角并涂哑光黑**（陷光）
- 窗后 0.5mm 处做一圈 **Ø51.6 × 0.8 的环形支撑台**，配 0.5mm 黑色 EVA 垫 → 板面压紧、不漏光
- 切平面外侧再留 3mm 环带贴**黑色植绒**（这是最容易被看到的区域）

### 后壳

- 外球 Ø99，与后壳在 X=8 处分界（前壳承担视区，后壳承担装配）
- 内部：板座（Φ51 沉台深 1.5）+ 4× M2 铜螺母柱
- 6× Φ4 散热/走线孔，开在**背面和底部**（正面绝不开口）
- 两壳对接：3× M2×8 螺丝 + 定位销 2×Ø3

### 消光（决定成败）

| 部位 | 处理 |
|---|---|
| 内胆外表面 | 哑光黑喷漆（或直接 PETG 哑光黑料打印），粗糙度 Ra≈3 |
| 内胆内表面 | 哑光黑 + 前部 15mm 环带贴植绒 |
| 窗口内壁 | 哑光黑，45° 倒角 |
| 屏边/FPC | 0.5mm 黑色 EVA + 黑色醋酸胶带包覆 |

> **禁止**：亮面黑、黑色 PET 光面打印、任何反光胶带。一点反光就会把"真空黑"变成"塑料黑"。

## 3.5 底座

| 部位 | 设计 |
|---|---|
| 外形 | Ø110 × 14，顶面 Ø104 凹球面（SR55，深 4），球落进去 |
| 材料 | V1：PETG 打印 + 哑光黑/香槟金喷漆；V1.0：6061 铝 CNC + 阳极氧化（¥90~120） |
| 内腔 | 电池仓 60×40×12（2000mAh 软包）、功放板位、喇叭腔 |
| 喇叭 | Φ28 8Ω 2W 带腔体，朝下出声，底盖开 Ø26 出声孔 + 防尘网 |
| 灯环 | 上沿 Ø104 环形槽（宽 3 深 2），内嵌 WS2812 16 灯 + 亚克力导光件（半透乳白） |
| 充电 | 后侧 Type-C 母座（沉 1.5，防插头翘） |
| 配重 | 底部环形钢片 100g |
| 底盖 | Ø104×3，4× M2 自攻 + 4× EVA 胶垫 |

### 重心核算

| 部件 | 重量 | 质心高（距底座底面） |
|---|---|---|
| 底座 + 电池 + 喇叭 + 配重 | ≈ 300g | ≈ 7mm |
| 球体（壳 + 内胆 + 板） | ≈ 205g | ≈ 62mm |

综合重心 ≈ (300×7 + 205×62) / 505 = **29.3mm**，远低于球心（≈54mm）。
→ 推不倒、拿走球体后底座也不倾。这是"桌面物件"和"玩具"的区别。

## 3.6 电连接（球 ↔ 底座）

**6 pin pogo（3.0mm 间距）**：

| Pin | 信号 | 说明 |
|---|---|---|
| 1 | +5V | 底座 → 球，给 AXP2101 供电/充电 |
| 2, 3 | GND | 双针，降接触电阻 |
| 4 | BCLK | I2S 位时钟 |
| 5 | LRCLK | I2S 帧时钟 |
| 6 | SDIN | I2S 数据（到底座的 MAX98357） |

- 磁铁 4×N35 Ø8×3 负责吸合与对中（吸力约 1.2kg，够）
- 定位：底座凸台外圆 Ø58 与接口环内孔 Ø60 形成 1mm 导向
- **断电保护**：球被拿起时 pogo 断开，板子自动切到内置小电池（可选 300mAh）或直接关机；建议 V1 不装内置电池，拿起即关机，放回即开机（还能当"拿起唤醒"的开关用）

## 3.8 散热

- 板上发热 ≈ 0.6~1.0W（Wi-Fi 常连 + 屏 40% 亮度）
- 内胆内腔体积 ≈ 434 cm³，闭死会到 45℃+
- 后壳背面 6× Ø4 孔 + 球底 Ø56 开口 → 形成"底进顶出"的对流
- 实测目标：室温 25℃，连续对话 30 分钟后球壳内壁 ≤38℃（手摸温热，不烫）

## 3.9 打印参数（拓竹 P2S）

| 件 | 材料 | 层高 | 填充 | 支撑 | 备注 |
|---|---|---|---|---|---|
| 内胆前壳 | PETG（首选）/ PLA Lite（可用） | 0.16 | 15% 螺旋 | 树状，仅窗内 | 前切面朝下打印，窗口朝上，免支撑 |
| 内胆后壳 | 同上 | 0.20 | 15% | 免 | 开口朝下 |
| 接口环 | PETG | 0.12 | 40% | 免 | 尺寸精度优先 |
| 底座 | PETG | 0.20 | 25% | 树状 | 顶面朝下打，凹球面免支撑 |
| 底盖 | PLA Lite | 0.20 | 20% | 免 | |

> 内胆建议 PETG：PLA 在密闭球内 40℃ 会软化变形（尤其窗框处）。若只有 PLA Lite，前壳必须 PETG，其余可用 PLA。
