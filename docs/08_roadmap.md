# 08 · 路线图与风险

## 8.1 四个阶段

### V0.1 · 光学验证（半天，¥75）

**目的：在花任何结构钱之前，确认"眼睛浮在黑球里"成立。**

- 买一组 Ø100 或 Ø110 亚克力半球
- 内胆不做，直接用**黑色卡纸卷一个 Ø95 的筒 + 圆形黑纸面**当临时内胆
- 微雪板贴在临时内胆后面 10mm，屏朝前，UI 跑全黑 + 两只胶囊眼
- 把球壳罩上，**在台灯下、暗室里各拍一张**

| 验收 | 判据 |
|---|---|
| 悬浮感 | 侧 30° 观察，眼睛明显在球壳后方 |
| 真空黑 | 暗室无灰雾、无漏光 |
| 玻璃感 | 球壳表面高光自然，不像塑料罩 |

> 这一步失败（比如球壳雾度大 / 高光太假）就换供应商或换玻璃球，**不要往下做结构**。

### V0.2 · 结构打样（2~3 天，¥120）

- 打印内胆前/后壳、接口环、底座、底盖
- 喷哑光黑，装配，验以下三项：
  - 屏与窗口同轴度（±0.3mm）
  - 内胆能否顺利进球（2.5mm 间隙够不够）
  - 接口环与底座的对中（磁吸是否自动吸正）

| 交付 | `hardware/stl/*.stl` + 装配照片 |
|---|---|

### V0.3 · 电子联调（2 天，¥96）

- 焊 8pin 排线、装 pogo、接 IP5306 / MAX98357 / WS2812
- 刷小智官方固件 → 喊"你好小智"能通
- 测：功耗、Wi-Fi 衰减、3m 唤醒率、喇叭音质

| 验收 | 待机 ≤1.0W，RSSI 衰减 <5dB，唤醒率 ≥90% |
|---|---|

### V0.4 · 软件与外观（3~5 天）

- 自研眼睛 UI（LVGL），9 个情绪状态
- 状态栏（时间/电量/WiFi）
- 灯环联动（说话律动）
- MCP 工具注册
- 外观：溶剂粘接 + 抛光（或先保持可拆）

### V1.0 · 定版（1 天）

- 换铝 CNC 底座 + 车削导光件（¥135 增量）
- 全项检验（见 07 章 7.5）
- 拍成品图 / 录 15s 演示

**总工期估算：9~13 个工作日（每天 3h 计），现金支出 ¥282（V1）/ ¥408（V1.0）**

## 8.2 风险表

| # | 风险 | 概率 | 影响 | 预案 |
|---|---|---|---|---|
| R1 | Ø110 亚克力球需开模费 ¥200~500 | 中 | 成本↑ | 改用 Ø100 现货（眼高 16mm，屏余量仍够） |
| R2 | 吹塑球雾度大、有流痕，玻璃感差 | 中 | **致命**（毁掉整个产品） | 换供应商；或改买"浇铸亚克力半球"；最后手段用玻璃球（贵 3 倍但质感最好） |
| R3 | 黑色 PETG 是碳黑，Wi-Fi 衰减 >10dB | 高 | 功能性 | 白料 + 喷漆；或天线处减薄到 0.8mm |
| R4 | AXP2101 无电池工况异常（反复重启） | 中 | 装配返工 | 球内加 300mAh 缓冲电池（¥15） |
| R5 | 内胆 Ø99 + 板 Ø51，装配空间太挤，FPC 折弯半径不够 | 中 | 装配困难 | 后壳改"开口碗"结构，先装板再合壳 |
| R6 | 合缝在光下可见，廉价感 | 高 | 观感 | V1.0 溶剂粘接 + 抛光；或接受"有缝"当设计语言（做一圈细金属环压缝） |
| R7 | 喇叭经 pogo 传输 I2S 有干扰/爆音 | 低 | 音质 | 加串联 33Ω + 磁珠；或退回"球内喇叭"方案 |
| R8 | 屏在球内温度过高，AMOLED 亮度衰减 | 低 | 长期 | 后壳开散热孔；屏亮度上限 80% |
| R9 | 亚克力球易刮花，用两周就花 | 高 | 观感 | 贴光学防刮膜（¥20）；或接受"使用痕迹" |
| R10 | 参考产品作者认为被抄袭 | 低 | 伦理 | 本项目仅自用复刻，仓库 README 已声明非商用、不售 |

## 8.3 待决策项（需要你拍板）

| # | 事项 | 选项 | 我的建议 |
|---|---|---|---|
| D-1 | **球径** | Ø100 现货 / Ø110 定制 / Ø120 大气 | **Ø110**；若模具费太高退 Ø100（影响很小） |
| D-2 | **底座材质** | 打印+喷漆 / 铝 CNC | V1 打印，V1.0 换铝（先验证再花钱） |
| D-3 | **喇叭位置** | 底座（I2S 过 pogo）/ 球内（模拟直连） | **底座**，音质差距明显；若爆音再退 |
| D-4 | **合缝** | 可拆卡扣 / 溶剂粘死 | **先可拆**，用 2 周确认无问题再粘 |
| D-5 | **状态栏** | 保留（叙事感）/ 去掉（更纯粹） | **保留**，但做成可关闭（长按切换） |
| D-6 | **球内电池** | 不装（拿起即关机）/ 装 300mAh（拿起还能亮 20min） | 先不装，看 AXP2101 实测 |

## 8.4 里程碑判据（不做假验收）

| 阶段 | 一句话判据 |
|---|---|
| V0.1 | 关灯拍照，朋友看到第一反应是"这是个玻璃球"而不是"这是个灯" |
| V0.2 | 内胆塞进球，不用蛮力，屏正对窗口不偏 |
| V0.3 | 隔 3 米喊它，它答应 |
| V0.4 | 连续看 3 分钟，眼睛不"死"（有微动、会眨眼） |
| V1.0 | 放在桌上，不知道的人会伸手摸 |
