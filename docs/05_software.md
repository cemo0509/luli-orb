# 05 · 软件方案

> 目标：**刷完固件，装壳，插电，它就会眨眼。** 不写一行代码也能跑（走小智官方固件），想改表情再加自己的 UI 层。

---

## 5.1 固件选型

| 方案 | 说明 | 结论 |
|---|---|---|
| **小智 xiaozhi-esp32**（78/xiaozhi-esp32，MIT） | ESP32 语音助手事实标准，流式 ASR+LLM+TTS，设备端 MCP，100+ 板卡配置 | ✅ **主线** |
| 小智 + 自研 UI 层 | 保留语音链路，替换表情/状态栏 | ✅ V0.4 起做 |
| 自己从零写 | 语音链路要重造（VAD/唤醒/协议） | ❌ 不值 |

小智硬性门槛（买板/换板时对照）：**Flash ≥16MB、PSRAM ≥4MB**。微雪 1.75-B 是 16MB + 8MB，达标。

## 5.3 眼睛引擎（本项目的灵魂）

### 参数化模型

眼睛不是贴图，是 **8 个参数画出来的**，这样任何表情都是参数插值，不会出现"两套图对不上"的跳变。

| 参数 | 范围 | 含义 |
|---|---|---|
| `eye_w` | 60~120 px | 眼宽（默认 74） |
| `eye_h` | 40~200 px | 眼高（默认 185） |
| `eye_gap` | 160~300 px | 中心距（默认 248） |
| `eye_y` | 180~300 px | 眼中心高度（默认 250） |
| `radius` | 0~100 % | 圆角（默认 50% = 胶囊） |
| `tilt` | −25~+25° | 整体倾斜（歪头） |
| `color` | HSV | 主色（默认 H=186, S=55%, V=95%） |
| `squint` | 0~1 | 压扁程度（用于 ^^ 笑眼） |

表情 = 关键帧参数组 + 缓动插值（ease-out-back 用于弹性，ease-in-out 用于平滑）。

### 状态机

```
        ┌──────┐  唤醒   ┌────────┐  识别完  ┌────────┐
        │ idle │───────►│ listen │────────►│ think  │
        └──┬───┘         └────┬───┘         └───┬────┘
           │ 静默 3min         │ 超时 8s        │ 首包音频
           ▼                  ▼                ▼
        ┌──────┐         ┌────────┐       ┌────────┐
        │sleep │         │ idle   │       │ speak  │
        └──────┘         └────────┘       └───┬────┘
                                               │ 播放完
    情绪叠加（任意状态可触发，5s 后回落）      ▼
        happy / sad / angry / shy / love ──► idle
```

| 状态 | 视觉表现 |
|---|---|
| idle | 眼高 185，缓慢呼吸（±3px，周期 4.2s），每 4~7s 随机眨眼 120ms |
| listen | 眼高 200（睁大），上移 8px，轻微左右扫视 |
| think | 眼高 150，整体右移+左移循环（像是在思考），色温偏冷 |
| speak | 眼高 170±(音量包络×20)，跟说话节奏起伏 |
| sleep | 眼高 6（一条线），亮度降到 15% |
| happy | 眼高 120 + squint 0.6，向上弯（^ ^），颜色偏暖 |
| sad | 眼高 150，下移 12px，tilt −8°，颜色降饱和 |
| angry | 眼高 90，tilt +12°，颜色偏红 |
| love | 眼高 185，色相转粉，外发光加强 |

### 性能

- 全屏 466×466 RGB565 = **434KB/帧**
- 目标 30fps → 13MB/s，QSPI 80MHz 完全够
- LVGL 双缓冲放 PSRAM，只刷新"脏矩形"（眼睛区域约 200×250px，占 23% 带宽）
- 切勿整屏重绘：会掉到 12fps 且功耗翻倍

## 5.4 状态栏（仿手机的叙事）

参考产品那条「WiFi / 16:19 / 电量」不是装饰，是叙事——它让用户觉得"这里住着一个人"。

| 元素 | 位置 | 说明 |
|---|---|---|
| WiFi 图标 | x 90~118, y 22 | 连通实心 / 断开空心 |
| 时间 | 居中 x 233, y 36，字号 26 | RTC + NTP 校准 |
| 电量 | 右侧 x 360~400 | 由 BASE_ID/ADC 读底座电量，4 格 |

> 注意：这条状态栏在 1.75" 屏上会占用顶部约 50px（11%），眼睛中心因此下移到 y=250。这是与参考产品的第一处偏离（他用的是更大的屏）。

## 5.5 MCP 工具（让大模型能"动"这个球）

在设备端注册，注册完就能用嘴控制：

| 工具名 | 参数 | 效果 |
|---|---|---|
| `self.eye.set_emotion` | emotion: enum | 切情绪（happy/sad/angry/shy/love/sleep） |
| `self.eye.set_color` | h, s, v | 改眼睛颜色 |
| `self.eye.blink` | times: int | 主动眨眼 n 次 |
| `self.light.set_rgb` | r, g, b | 底座灯环颜色 |
| `self.light.set_mode` | mode: enum | off/breath/pulse/rainbow |
| `self.audio.set_volume` | 0~100 | 音量 |
| `self.sys.get_status` | — | 返回电量/温度/运行时长 |
| `self.sys.sleep` | — | 进入休眠 |

云端 MCP 再挂：电脑控制（`xiaozhi-mcp-computer`）、天气、日历 —— 于是可以说"帮我把电脑静音，然后生气给我看"。

## 5.6 配网与 OTA

- 首次上电：设备开 AP（`LULI-XXXX`），手机连上 → 选 Wi-Fi → 扫码绑定
- 绑定平台：小智官方服务器（免费额度）或自建 `xiaozhi-esp32-server` + DeepSeek
- OTA：小智自带，固件版本号写进状态栏长按 3 秒显示
- 恢复出厂：长按 PWR 10s

## 5.10 一条必须守的规矩

**屏幕内容的黑必须是 `#000000`。** 任何一次 UI 改版把背景改成 `#0A0A0A` 或加了半透明遮罩，光学效果当场失效（见 02 章 2.3）。建议在代码里写死：

```c
#define UI_BG  lv_color_hex(0x000000)   // 禁止修改，改了这个产品就废了
```

并在 CI 里加一条 grep 检查。
