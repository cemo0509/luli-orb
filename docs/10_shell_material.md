# 10 · 球壳材料：为什么之前写了亚克力，以及为什么该改玻璃

> 先说结论：**你的直觉是对的，成品应该用玻璃。**
> 我之前写亚克力，用的是"打样逻辑"（能开孔、不碎、便宜、三天到货），
> 但那三条都是**试错成本**的理由，不是**成品质感**的理由。产品最终长什么样，由这颗球决定。

---

## 10.1 一个反直觉的事实：玻璃的接缝反而更容易隐形

大多数人以为"玻璃没法粘、缝一定很明显"，实际正好相反：

| | 亚克力合缝 | 玻璃合缝 |
|---|---|---|
| 方式 | 溶剂（二氯甲烷/氯仿）毛细渗透，溶解-再聚合 | 折射率匹配 UV 胶 |
| 界面 | 溶剂挥发会在界面留一道**微雾带**，强侧光下可见 | 胶固化后 n≈1.50，与玻璃 n=1.50~1.52 **几乎相同** → 界面不产生反射 |
| 打磨 | 必需 800→3000 目 + 抛光膏，抛过头会"塌边" | 不需要打磨，胶层本身隐形 |
| 极限 | 好能做到"不明显" | 可以做到**物理消失**（光学件胶合就是这么干的） |

前提是四条：胶层厚度均匀（0.02~0.05mm）、无气泡、无灰尘、UV 能照到整圈。这四条都可控。

**所以在"看不出接缝"这件事上，玻璃比你们想象的强，亚克力反而更弱。**

## 10.2 三种材料横向对比

| 指标 | 亚克力 PMMA | 钠钙玻璃 | 高硼硅 3.3 | PC |
|---|---|---|---|---|
| 透光率 | 92% | 91% | 92% | 89% |
| 折射率 | 1.49 | 1.51 | 1.47 | 1.58 |
| 密度 | 1.19 | 2.50 | 2.23 | 1.20 |
| 表面硬度 | HB~2H | 5.5 莫氏 | 5.5 莫氏 | 2B |
| **耐刮** | ❌ 两周满身细划痕 | ✅ | ✅ | ❌ |
| 泛黄 | 3~5 年可见 | 不泛黄 | 不泛黄 | 1~2 年 |
| 可开孔 | ✅ 钻/铣/激光 | ⚠️ 金刚石+水，靠厂家 | ⚠️ 同左 | ✅ |
| 抗摔 | ✅ 裂而不碎 | ❌ 碎成片 | ❌ 碎（更细） | ✅ |
| 合缝质量 | 中（雾带） | **优（隐形）** | **优** | 中 |
| Ø100×2.5 壳重 | 93 g | **196 g** | 175 g | 94 g |
| 单价 | ¥10 | ¥15~35 | ¥40~80 | ¥15 |
| 交期 | 3~5 天 | 7~15 天 | 15~20 天（定制） | 3~5 天 |

**结论**：玻璃在"质感 / 耐刮 / 接缝 / 不泛黄"四项上完胜；亚克力只在"好加工 / 摔不碎"上赢。
一件摆在桌上天天被摸的东西，耐刮和不变色比"摔不碎"重要得多。

## 10.3 玻璃方案的真实难点（三个）与解法

### 难点 1：开孔

球壳底部要一个 Ø50 的口走线 + 落座。

| 解法 | 做法 | 评价 |
|---|---|---|
| **A 买"带口半球"（推荐）** | 玻璃吹制半球天生有一个口（脱模口/灯头口），下单时指定口 Ø50±2 | ✅ 最省事，通常不加钱 |
| B 让厂家后期开 | 金刚石套料钻 + 水冷，+¥10~20/件 | ✅ 可行，需提前说 |
| C 自己开 | 金刚石开孔器 | ❌ Ø50 在 2.5mm 薄壁上崩边率 >50%，别试 |
| D 不开孔 | 球底切平 + 粘一片带孔平板玻璃 | ⚠️ 工艺更复杂，接缝更多 |

> 现货玻璃球灯罩的口一般是 Ø30~45，Ø50 需要跟厂家说。

### 难点 2：内胆怎么塞进去

内胆 Ø90，任何小于 Ø90 的口都塞不进去。所以：

**必须两半球可开合，且装配顺序固定：**
1. 下半球（带 Ø50 口，口朝下）平放
2. 内胆从**赤道敞口**放进去
3. 上半球盖上
4. 沿赤道 UV 胶合

顺序反了（先粘后装）就永远装不进去。

### 难点 3：重量与安全

- 玻璃壳 196g（亚克力 93g），整机从 505g → **约 610g**
- 摔了是**碎成片**，不是裂
- 对策：
  - 底座做成**杯托**，包住球下部 18~20mm（防滚 + 缓冲 + 遮住 Ø50 口）
  - 底托贴 EVA 胶垫
  - 玻璃件一定要求**退火**（不退火的玻璃装螺丝/受热会自爆）

## 10.5 UV 粘接工艺（决定接缝能不能隐形）

| 项 | 要求 |
|---|---|
| 胶 | 光学级 UV 胶，固化后 **n = 1.49~1.51**，透光 ≥92%，雾度 <0.5%，**脂肪族**（不黄变） |
| 胶层 | 0.02~0.05mm。用 0.03mm 的鱼线/垫片垫在赤道上控制间隙 |
| 对位 | 3D 打印"赤道对位环"（内径 100.2，上下各半），保证两半球同轴 |
| 固化 | 365nm UV 灯，绕圈每 30° 照 30s，共 6min；胶厚处加倍 |
| 清洁 | 无水乙醇 + 无尘布，粘前必须擦，一粒灰就是一条白线 |
| 溢出 | **固化前必须擦净**。固化后只能刀刮+抛光，必留痕 |
| 检验 | 侧光 45° 看接缝；偏光镜看应力；指甲刮不动 |

> 国内可直接买"光学 UV 胶 无影胶 低雾度 折射率1.49"，¥40~80/20g，够粘 3~4 对球。

## 10.6 路线调整：玻璃主线，亚克力只做一次验证件

| 阶段 | 球壳 | 目的 |
|---|---|---|
| V0.1 光学验证 | **亚克力 Ø100**（¥10，3 天到） | 确认屏/内胆/眼睛效果，废了不心疼 |
| V1.0 成品 | **玻璃 高硼硅 Ø100，2.5mm**（¥35，15 天） | 最终质感 |

两条线的**结构尺寸完全通用**：

| 件 | 亚克力 3.0mm | 玻璃 2.5mm | 差异 |
|---|---|---|---|
| 球壳内径 | Ø94 | Ø95 | +1 |
| 内胆外径 | Ø89 | Ø90 | +1 |
| 屏距 | 11 | 11 | 0 |
| 前切面 | Ø52.3 | Ø52.6 | +0.3 |
| 底板余量 | 0.7 | 0.8 | 都够 |

→ **换壳时内胆只需把外径从 Ø89 改成 Ø90**，其余不动。`params.py` 一条命令就能重出：

```bash
python hardware/params.py 100 11 3.0    # 亚克力验证件
python hardware/params.py 100 11 2.5    # 玻璃成品
```

**如果你不想做两套**：直接买玻璃，跳过亚克力。代价是首件可能因开孔偏差/圆度公差报废，试错成本从 ¥10 变成 ¥35 + 15 天。

---

## 10.7 一句总结

我之前的方案里，亚克力承担的是"让你快点看到东西"的角色，它从来不是这个产品该有的材料。
**玻璃负责质感，亚克力负责试错**——两者都留着，只是分工要说清楚。
