# 12 · 面部 UI：五种设计语言

> 目标不是"做一个好看的动画"，而是让这颗球**看起来是活的**。
> 参考产品的胶囊眼只是入门线，我们可以在它之上做真正的区别。

打开 `tools/face-lab.html` 可以实时切换五个方向（支持 `?c=tide&s=listen` 直接进入某个组合）。

---

## 12.1 三条设计原则

| # | 原则 | 反面 |
|---|---|---|
| 1 | **运动的最小单位是"呼吸"，不是"动效"** | 眼睛到处乱飞、缩放弹跳 → 像玩具 |
| 2 | **情绪靠"张力"表达，不靠"图标"** | 画个爱心表示开心、画个雨云表示难过 → 像表情包 |
| 3 | **任何时候都要有微变化** | 完全静止 3 秒就会被判定为"一张图" |

第 3 条最容易被忽略：idle 状态必须有 0.3px 级的随机漂移 + 4~7 秒一次的眨眼。缺了这个，屏幕再漂亮也是死的。

---

## 12.2 五个方向

### ① 蛾眼 Moth — 实心胶囊（最稳，最接近参考）

- **构造**：圆角矩形填充 + 三层递减外发光 + 顶部内高光
- **动效**：呼吸缩放 ±3%、眨眼 130ms、listen 时整体睁大 14%
- **独特性**：★★☆ —— 本质上和参考产品同源，但光晕更柔、内高光更讲究
- **风险**：最低。AMOLED 上必成
- **适合**：想先跑通，日后再升级

### ② 潮汐 Tide — 液态光（有生命感）

- **构造**：左右边缘用两组不同频率的正弦叠加，形状始终在缓慢起伏；两眼相位差 0.9rad，像两个独立的液滴
- **动效**：频率随状态变（idle 0.7Hz → speak 1.55Hz）；眨眼时液体被"压扁"
- **独特性**：★★★★ —— 市面上几乎没有 AI 硬件用液态眼光
- **风险**：中。形状每帧重算，466px 下 26 段贝塞尔，ESP32-S3 完全跑得动（<2ms）
- **适合**：想要"活的、有机的"感觉

### ③ 星野 Starfield — 粒子（最神秘）

- **构造**：眼体只保留 10% 透明度的底，内部 46 颗星点各自闪烁 + 一团缓慢旋转的星云
- **动效**：星点相位独立；眨眼时眼睛收成一条"星线"；think 时星云转速加快
- **独特性**：★★★★★ —— 这个几乎没人做过，而且**只有 AMOLED 能做**（LCD 的灰底会让星点糊成一片）
- **风险**：中低。46×2 个圆，一次 drawArc，成本可忽略
- **适合**：想做成"里面有宇宙"的产品叙事

### ④ 息 Breath — 双光斑（最抽象）

- **构造**：没有眼睛。两团径向渐变光斑，此消彼长（相位差 π），外面一圈极细 16% 透明度的环
- **动效**：光斑半径 ±16% 呼吸；speak 时呼吸跟着音量包络
- **独特性**：★★★★ —— 完全摆脱"眼睛"这个范式，更像生物发光
- **风险**：低。但**认知成本高**：用户第一眼可能不知道"它在看我"
- **适合**：极简主义路线，愿意承担"不像人脸"的代价

### ⑤ 晷 Dial — 线框（最克制）

- **构造**：2px 描边的空心胶囊 + 下半圈刻度 + 一根随相位摆动的指针
- **动效**：指针缓慢摆（sin 0.8Hz）；眨眼时描边收成一条线
- **独特性**：★★★★ —— 工业仪表感，和"玻璃球"形成理性/感性的冲突
- **风险**：低。纯描边，功耗最低
- **适合**：想强调"工具"而不是"宠物"

## 12.3 状态 × 概念 的可实现性

| 状态 | 蛾眼 | 潮汐 | 星野 | 息 | 晷 |
|---|---|---|---|---|---|
| idle | ✅ | ✅ | ✅ | ✅ | ✅ |
| listen | ✅ 睁大 | ✅ 频率↑ | ✅ 星点聚拢 | ✅ 光斑变大 | ✅ 指针停 |
| think | ✅ 缩窄 | ✅ 低频 | ✅ 星云加速 | ⚠️ 难表达 | ✅ 指针快摆 |
| speak | ✅ 随音量 | ✅ 随音量 | ⚠️ 星点抖动 | ✅ 随音量 | ✅ 刻度跳动 |
| happy | ✅ 弯成 ^ ^ | ✅ 上翘 | ✅ 星点外扩 | ⚠️ 只能变亮 | ✅ 指针上扬 |
| sleep | ✅ 一条线 | ✅ 摊平 | ✅ 全暗只余 3 颗 | ✅ 微光 | ✅ 一根横线 |

**结论**：蛾眼、潮汐、晷三者的状态覆盖度最好；星野在 speak 上偏弱；息在 think/happy 上表达力不足。

## 12.4 我的建议

**主线做「潮汐」，备用「蛾眼」。**

理由：
1. 潮汐的"液态"和这颗玻璃球的气质最搭——玻璃是静的，光是流的
2. 它保留了"两只眼睛"的基本语义，用户不会认不出来
3. 状态覆盖度满分
4. 计算量可控，ESP32-S3 上 466px 全屏 30fps 无压力
5. 蛾眼作为 fallback：如果潮汐在实机上行锯齿或抖动明显，一行开关切回去

**不建议一开始做星野**：它最惊艳，但也最吃"黑得干净"——一旦内胆消光没做好，星点会被环境反光糊掉，效果反而塌。

## 12.5 落地到固件的参数

眼睛几何（Ø70 球，1.75" 屏）：

| 参数 | 值 | 说明 |
|---|---|---|
| eye_w | 47 px | 眼宽（球径 6.4%） |
| eye_h | 117 px | 眼高（球径 16%） |
| eye_gap | 157 px | 中心距（球径 21.5%） |
| 中心 y | 233 | 屏垂直中心 |
| 主色 | H=186°, S=55%, V=95% | 冷青 |
| 外发光 | 半径 14~28px，alpha 0.55 | 三层递减 |

> 若改用 1.43" 屏（Ø36.75），上述像素值需 ×1.21：67 / 142 / 190。

潮汐的形状算法（可直接移植）：

```c
// 每帧对 26 段采样，左右边缘各自叠加两组正弦
for (int i = 0; i <= 26; i++) {
    float p = i / 26.0f;
    float y = cy - h/2 + h * p;
    float wob = sinf(p*M_PI*3 + ph) * hw*0.14f
              + sinf(p*M_PI*5 + ph*1.7f) * hw*0.05f;
    left[i]  = cx - hw + wob;
    right[i] = cx + hw + wob * -1.0f;   // 反相，形成液滴感
}
```

## 12.6 与参考产品的关系

参考产品的胶囊眼是**正确的起点**，但它只有一盏常亮灯——没有液态、没有粒子、没有随状态变化的质感。
我们的差异化不靠"更花哨"，靠 **"同一双眼睛，有五种情绪下的物理表现"**。

这是它看起来"活着"、而别人的只是"亮着"的原因。
