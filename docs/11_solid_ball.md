# 11 · 实心球假设：如果那颗球是实心的，结构会怎样

> 你手上的照片确实像实心球（内部有光导的质感、能透过球看到手掌且被放大）。
> 但这里有一个物理事实必须先说清楚：**实心球里放不进屏幕，"面部内容"不可能在球里面。**
>
> ⚠️ **本文在 11.10 / 11.11 两节做了修正：真正的正解是「实心半球」而不是整球**。
> 整球那一套（放大 3.5×、屏顶在球外）是错的路径，保留在文中只作为对照。

---

## 11.1 两种完全不同的解释

| | H1 空心薄壁球 | H2 实心球 |
|---|---|---|
| 球是什么 | Ø100，壁厚 2.5，中空 | Ø100，实心 K9/亚克力 |
| 屏在哪 | **球里面**，内胆前窗后 11mm | **球后面**，贴着球的后表面 |
| 你怎么看到眼睛 | 透过透明球壳看里面 | 球本身是透镜，把后面的屏**放大**后投到眼前 |
| 放大率 | **1.0×**（同心薄壁球净光焦度≈0） | **3.0~3.9×** |
| 屏上眼高 | 17.6mm（185px） | **4.5mm（48px）** |
| 可见屏径 | 全屏 Ø44.4 | 只有中间 **Ø28** |
| 球重（Ø100） | 196g | **1314g** |

**这两个假设对 UI 的要求差了 4 倍**（185px vs 48px）。所以必须先把这件事定下来，否则后面全白做。

---

## 11.2 实心球的光学账（`hardware/ball_lens.py` 可复算）

球透镜：EFL = nR/(2(n−1))，n=1.51 时 EFL = 1.5R。屏在球后 3mm 时：

| 球径 | EFL | 放大率 | 可见屏径 | 屏上眼高 | 球重 |
|---|---|---|---|---|---|
| Ø80 | 59.2 | 3.65× | 21.9mm | 3.5mm（37px） | 673g |
| Ø90 | 66.6 | 3.58× | 25.2mm | 4.0mm（42px） | 958g |
| **Ø100** | 74.0 | **3.52×** | 28.4mm | **4.5mm（48px）** | **1314g** |
| Ø110 | 81.4 | 3.48× | 31.6mm | 5.1mm（53px） | 1749g |

屏距越远放大越狠、可见区越小（Ø100）：

| 屏距 | 0mm（贴死） | 3mm | 5mm | 8mm | 12mm | 20mm |
|---|---|---|---|---|---|---|
| 放大率 | 3.08× | 3.52× | 3.89× | 4.62× | 6.16× | 18.4× |
| 可见屏径 | 32.5 | 28.4 | 25.7 | 21.6 | 16.2 | 5.4 |

**推论**：如果走实心球，屏幕只能贴死在球后 0~3mm；你看到的那一整块黑，其实全是屏幕像素被放大出来的，**根本不需要"黑内胆"**——球自己的轮廓就把视场裁掉了。

## 11.3 5 分钟判定实验（先做这个，别猜）

如果你手上已经有那两颗球，做三件事，一次就能定：

| 实验 | 实心球 | 空心薄壁球 |
|---|---|---|
| **① 放报纸上** | 字被放大 **3 倍左右**，边缘明显变形、有彩虹边 | 几乎不放大（1.0×），只有轻微位移 |
| **② 手电贴球侧照** | 能看到光线在球内**全反射绕一圈**，整个球发亮 | 只看到壁厚那一圈亮 |
| **③ 把手指放在球后 10mm 看** | 手指被放大且**模糊发散**（像透过灯泡看） | 手指原尺寸，清晰 |
| **④ 称重** | Ø100 约 1.3kg，Ø80 约 0.67kg | Ø100 约 0.2kg |

> 第 ④ 条最省事：**一个 Ø100 实心玻璃球 1.3 公斤**，拿在手里立刻就知道。视频里单手托球的样子，如果轻飘飘就是空心。

**还有一个便宜的验证法**：花 ¥10 买一颗 Ø60 的**实心亚克力球**，把手机屏贴上去看——放大效果立刻出现。这是最快、最便宜的一次实验，比我们在这里争论有用。

## 11.4 如果判定是实心球（H2），结构反而大幅简化

| 环节 | H1 空心 | H2 实心 |
|---|---|---|
| 球壳开孔 | 要 Ø50 底孔 | **完全不用开孔** |
| 合缝粘接 | 两半球 UV 胶，工艺重 | **没有接缝** |
| 装配 | 内胆塞进赤道敞口再合球 | **屏贴上、黑壳扣上、拧 4 颗螺丝，10 分钟** |
| 维修 | 拆球（可能拆坏） | **拧螺丝就拆** |
| 内胆 | Ø90 打印件 + 消光 | **一个黑色后壳罩**（半球或筒），把球的背面和屏幕一起包住 |
| 灯环 | 底座 | **黑壳与球的交界处**（正好是参考视频里那个"环"） |

### H2 的零件表

| # | 件 | 说明 |
|---|---|---|
| 1 | 实心玻璃球 | K9 Ø80~100，抛光，¥120~300 |
| 2 | 黑后壳 | PETG 打印，半球或碗形，内壁哑光黑，前缘贴 EVA 压住球 |
| 3 | 屏 | 1.75-B 板，屏面贴球后表面（0~3mm） |
| 4 | 遮光筒 | 屏到球面之间一圈黑泡棉/黑筒，防漏光 |
| 5 | 底座/机身 | 与黑后壳一体或分件，内含电池、喇叭、灯环 |
| 6 | 脚垫 | EVA |

**去掉了**：内胆、接口环、pogo、磁吸、玻璃开孔、UV 粘接、抛光。整机零件从 10 个降到 6 个。

### H2 的代价（必须接受）

| 代价 | 量化 | 影响 |
|---|---|---|
| **重** | Ø100 球 1314g，整机 ~1.6kg | 桌面摆件级重量，底座要能扛 |
| **像差** | 边缘严重球差+色差 | 只能看到中心 Ø28，所以眼睛必须做小（48px），且不能有大面积浅色内容 |
| **视角窄** | 侧 30° 看，眼睛会明显偏移和虚化 | 只能正面对着看，不能做成"会转头" |
| **画面质量** | 有效分辨率被压缩到中心 28mm | 466px 屏 → 实际显示 28mm ≈ 294px，仍然够 |
| **成本** | 球 ¥120~300（vs 亚克力 ¥10） | 单件成本上去，但省了整套内胆件 |

## 11.5 我的判断（坦白说）

- **从视频证据看**：6 秒那帧"透过球看 PCB 被放大"是最强证据，倾向 **H2 实心**。
- **从画面稳定性看**：球透镜在偏轴时有严重像差，视频里镜头转来转去眼睛仍然清楚，又有点像 **H1**。
- **从工艺看**：H2 对一个手工 DIY 的人友好太多了（不用开孔、不用粘、不用抛光），所以作者选 H2 的概率很高。
- **结论**：不下结论，**先做 11.3 的四条实验**。花 10 块钱、5 分钟，比我在这里推理一小时准。

## 11.9 实心球对结构的两个硬约束

### ① 屏必须"压"在球后表面（0~2mm）

球是透镜，屏离球越远放大越狠、可见区越小（见 11.2 表：3mm→Ø28，8mm→Ø21.6，12mm→Ø16）。
所以结构上要做：**球被黑后壳的环形台阶定位 + 屏座后面加泡棉/弹簧往前顶**，靠弹性保证贴合，不靠硬压（玻璃会崩）。

### ② 球是导光的，必须整体遮光

屏幕的光射进球后，会在球内全反射走一段再从侧面漏出来。所以：

- 黑后壳要把球**从后往前包到赤道**（包住 ≥50% 球面）
- 黑壳与球的接触处贴一圈黑色 EVA/硅胶，堵住漏光缝
- 屏周围一圈黑色遮光筒，避免光直接打在球的内壁

**这一条做不好，球会变成一个发光的灯泡，而不是"黑面上一双眼睛"。**

## 11.10 半球（平背）其实比整球更对

淘宝上最常见的实心件不是"整球"，是"**亚克力实心半球**"：Ø100 那档标的厚度是 **49mm ≈ 半径**。
这不是凑巧——**平面正好过球心**，这个几何关系让半球在光学上比整球更优。

### 为什么半球更好（四条硬理由）

| # | 理由 | 说明 |
|---|---|---|
| 1 | **中心成像零位移、零放大、零畸变** | 平面过球心 → 球心那一点的所有入射光线都垂直于球面，不折射。所以屏幕中心的像素**原样出现在球心**，眼睛真的"浮"在球的正中心，而且是**锐利**的。整球做不到（整球 m≈3.5，边缘发虚） |
| 2 | **平面背 = 天然的装配基准** | 屏幕/遮光板直接贴在平面上，4 颗螺丝压紧，**没有缝隙、没有漏光、没有 0~2mm 的间隙公差**。整球要"把屏顶在球面上还不能压碎"，是这个方案里最难的一环 |
| 3 | **便宜一个数量级** | Ø100 实心半球 ¥15~25；K9 整球 ¥100~200 |
| 4 | **可加工** | 卖家详情页自己写了"可以打孔、丝印、上色、胶水粘"——装饰件本来就是给 DIY 用的 |

### 光路对比（同一颗 Ø100）

```
整球（球透镜）                    半球（平背）
   ┌───────┐                        ┌───────┐
   │  ●屏  │ m=3.52                 │  ●屏  │ m≈1.0
   │   ↓   │ 可见区只 Ø28           │   ↓   │ 全屏 1:1
   │  ( )  │ 球差/色差明显           │  ( )  │ 中心锐利、边缘自然渐晕
   └───────┘                        └───────┘
   屏在球外 3mm                     屏贴在平面背面
```

### 由此推出的正解结构

```
        透明实心半球（Ø100，平背）
        ┌──────────────┐
        │              │   ← 眼睛出现在球心，锐利
        │     ◉ ◉      │
        │ ──────────── │   ← 平面（球心所在平面）
        │ 黑遮光板 Ø86  │   ← 中间开 Ø50 窗，贴屏
        │ 屏 Ø44.4     │
        └──────────────┘
              │ 4×M2
        ┌─────┴──────┐
        │  机身/底座  │  ← 电池/功放/喇叭/灯环
        └────────────┘
```

从正面看 = 一整块黑里浮着两只眼（黑遮光板 Ø86 占球径 86%，与参考视频的 85~90% 完全吻合）。

### 一个必须注意的副作用：会往前倾

半球的重心在球心**前方** `3R/8 = 18.75mm` 处（整球重心在球心，半球不在）。
所以：
- 底座必须做**凹球面托座**（SR50，深 8~10mm），把半球托住
- 或者在机身里、球的后下方加 50~100g 配重
- 平背朝后 + 后方有电池 → 重心会被拉回来，实际影响不大

### 验收（装饰件出厂 ≠ 光学件）

| 检查 | 做法 | 不合格 |
|---|---|---|
| 面型 | 强光斜照球面，看反射的灯管是否**笔直** | 灯管像波浪 = 有流痕，眼睛会糊 |
| 气泡 | 白纸垫底，强光看内部 | 有明显气泡/杂质就退 |
| 厚度 | 卡尺量 Ø100 应 **49±1mm** | 明显薄于半径 = 是"球缺"不是半球，球心对不上 |
| 边缘 | 看平面与球面交界处是否平整 | 有毛边/崩口要磨 |

> 装饰级只保证"够亮"，不保证面型。**买回来第一件事是用强光照一下看反射的灯管直不直**——这一条比什么都准。

### 重量对照（实心半球）

| 规格 | 亚克力 | K9 玻璃 |
|---|---|---|
| Ø80 半球（厚 40） | **160g** | 337g |
| Ø100 半球（厚 49） | **312g** | 657g |

> 比整球轻一半以上（整球 Ø100 亚克力 623g / 玻璃 1314g）。312g 拿在手里正好是"有分量但不压手"，比 1.3kg 更适合桌面。

## 11.11 我为什么会想到"整球"，以及 ½ 球 / ¾ 球的定量对比

### 我错在哪（复盘）

1. **套用了现成品类**。我先搜到 `lensball` 这个品类，它全是整球，于是把"整球"当成了前提，没去质疑。
2. **被剪影骗了**。视频里球的外轮廓是一个完整圆，我就默认它是完整体积。其实**半球从正面看也是完整圆**。
3. **把"放大"当成了必需特征**。整球 m=3.5 能解释"眼睛变大"，但半球 m=1 也能解释（屏幕本来就是那么大的眼睛），而且更清晰。我从"需要放大"倒推"必须是整球"，这一步是错的。

**结论：你说的对，½ 球或 ¾ 球才是正解。整球反而是最差的一档。**

### 三种球缺的定量对比（Ø100 亚克力）

| | 半球（h=50） | ¾ 球（h≈67.5） | 整球（h=100） |
|---|---|---|---|
| 平面位置 | **过球心** | 球心后 17.5mm | 球心后 50mm（即背面） |
| 屏幕贴在哪 | 平面背面 | 平面背面 | **球外的切点，只能"顶"着** |
| 放大率 | **1.00×** | ≈1.05× | **3.5×** |
| 中心画质 | **锐利**（光线垂直入射不折射） | 基本锐利 | 明显球差 |
| 可见屏径 | 全屏 Ø44.4 | 全屏 | 只 Ø28 |
| 重量 | **312g** | 468g | 623g |
| 装配 | 平面打 4 个孔，螺丝压紧 | 同左 | 要做一个"弹性顶球"机构 |
| 侧面观感 | 平背要藏 | **最像整球** | 完整 |

### 结论：买半球，用后壳"补"成 ¾ 球

¾ 球的好处是**侧面更包裹**（玻璃向上翻 135°），但你不需要真的买到 ¾ 球：

> **半球 + 黑后壳包到赤道以上 20mm = 视觉上完全等于 ¾ 球。**

因为那圈多出来的玻璃本来就被黑壳挡住了。淘宝上 ¾ 球几乎搜不到，半球到处都有，所以**买半球就对了**。

### 唯一要注意的：平背的"边缘"

半球平背与球面的交界是一圈 90° 的硬边。从正面看不出来（被遮光板挡住），但从侧面 45° 会看到一条平直的轮廓线。
处理办法：**黑后壳的上沿做成 SR50 的内凹弧面，正好贴住这条边**，看起来就是"球嵌进壳里"。

### 修正后的零件表（删掉整球那套）

| # | 件 | 规格 | 数量 |
|---|---|---|---|
| 1 | **亚克力实心半球** | Ø100 厚 49，或 Ø80 厚 40 | 各 2 |
| 2 | 黑遮光板 | Ø86 × 2，中间开 Ø50 窗，哑光黑 | 1 |
| 3 | 屏模块 | 微雪 1.75-B | 1 |
| 4 | 后壳 | PETG，内凹 SR50，包到赤道以上 20mm | 1 |
| 5 | 底座/机身 | 含电池、功放、喇叭、灯环 | 1 |

**不需要了**：整球、弹性顶球机构、0~2mm 间隙控制、球透镜的像差补偿。

## 11.13 一定要实心吗？——不用，光学上是等效的

### 先给结论

**不需要实心。厚壁空心半球罩 + 屏放在球心平面上，和实心半球的光学效果完全一样。**

### 为什么（一句话物理）

同心球壳（内外球同心的半球罩）每一个面都是"球面，且曲率中心重合在球心"。
把屏幕放在**球心所在的平面**上，屏幕上任何一点发出的光，打到内外两个球面时**入射角都是 0°**——不折射。

> 不折射 = 不放大、不位移、不畸变。所以你看过去，屏幕就在它原来的位置、原来的大小。
> 实心半球能做到这一点，是因为它的平面恰好过球心；**空心罩把屏放在罩口平面，同样过球心，效果一模一样。**

### 那实心和空心的真正差别在哪

| | 实心半球 | 厚壁空心罩 | 薄壁空心罩 |
|---|---|---|---|
| 屏位置 | 平面背面（球心面） | 罩口平面（球心面） | 同左 |
| 光学 | m=1、无畸变 | **同样 m=1、无畸变** | 同左 |
| 视觉厚度 | 饱满、有"晶体"感 | 壁厚够就够饱满 | ❌ 空、薄、廉价 |
| 重量 Ø90 | **227g** | 68~101g | 42g |
| 加工 | 车削 + 抛光（面型好） | 吹塑/热成型（有波纹） | 吹塑 |
| 价格 | ¥59~96 | ¥20~45 | ¥10~20 |
| 装配 | 平背贴屏，最简单 | 罩 + 黑封板，也简单 | 同左 |
| 压裂风险 | 低 | 中（壁薄处） | 高 |

**决定成败的不是"实心"，是「面型」和「壁厚」。**

### 壁厚选多少（Ø90）

| 壁厚 | 重量 | 评价 |
|---|---|---|
| 3mm | 42g | 太薄，看着空、容易压裂 |
| **5mm** | **68g** | ✅ 最低可用，有厚度感 |
| 6~8mm | 79~101g | ✅✅ 最推荐，接近实心的视觉 |
| 实心 | 227g | 好，但重且贵 |

### 怎么一眼认出是实心还是空心

| 方法 | 实心 | 空心 |
|---|---|---|
| **看底部边缘** | 一条锋利边，没有"墙" | 能看到**一圈墙的厚度**（你截图里就是这种） |
| **从底部往里看** | 看不到内腔，全是料 | 能看到**内壁的第二个球面** |
| **掂重量** | Ø90 必须 ≈225g | Ø90 只有 60~100g |
| **看阴影** | 内部均匀 | 内壁有第二道高光/阴影 |

> 你这两张图里，底部有一圈明显的"墙"，从侧面还能看到内壁的第二道反光——**大概率是厚壁空心罩**。
> 最省事的确认方式：问客服"**Ø90 这个单个多重？**"。227g 是实心，80g 左右是空心，一问就清楚。

### 如果是空心罩，结构反而更简单

```
      透明半球罩（Ø90，壁厚 5~8）
      ┌──────────────┐
      │              │
      │    ◉  ◉      │  ← 屏贴在封板中央，正好在球心平面
      │ ───────────  │  ← 罩口平面 = 球心平面
      │ 黑封板 Ø90    │  ← 3D 打印/亚克力，内侧哑光黑
      └──────────────┘
              │ 4×M2
      ┌──────────────┐
      │   机身/底座   │  电池·功放·喇叭·灯环
      └──────────────┘
```

- **黑封板**同时干三件事：封住内腔、当屏幕安装基准、当"黑面"
- 比实心少一道工序（不用在实心块上打孔），也不用担心压裂实心件的平面
- 唯一要额外做的是**罩口与封板的密封**（一圈黑 EVA 或硅胶，兼作遮光）

### 所以怎么选

| 情况 | 买什么 |
|---|---|
| 能买到 5~8mm 厚壁、面型好的罩 | ✅ 优先，轻、便宜 |
| 罩很薄（3mm）或波纹明显 | 买实心半球 |
| 拿不准 | **问重量**。80g=空心罩可用（若面型好），225g=实心 |

> 一句话：**眼睛锐不锐，靠的是面型，不是实心。**

## 11.14 决策：资金有限时，这 ¥59 该怎么花

### 结论：买实心 Ø90（¥59），不要为省 ¥20~30 去赌空心

光学上空心能用（11.13），但**装配上有三个实心没有的风险**，每一个都能让"真空黑"当场破功：

| 风险 | 实心 | 空心罩 |
|---|---|---|
| **① 罩口平不平** | 平面是车出来的，绝对平 | 吹塑/热切的边，常有 0.2~0.5mm 波浪 |
| **② 封板漏光** | 不存在，屏直接贴平面 | 罩口与封板之间只要有一条 0.1mm 缝，屏的光就会漏出来，在罩壁上打出一圈**亮线** |
| **③ 面型** | 车削+抛光，可控制在几个波长 | 吹塑件有水波纹，眼睛会"雾" |

### 算一笔账

| 方案 | 支出 | 额外工 | 失败代价 |
|---|---|---|---|
| 实心 Ø90 | **¥59** | 0 | 低 |
| 空心罩 Ø90 | ¥25~40 | 做封板、配密封圈、调平罩口（+2 天） | 漏光/雾化 → 整件重来 |

省下 ¥20~30，但要额外做一块封板、一段密封、一次调平；一旦漏光，这 ¥30 变成几百块返工。

> 资金有限时，**最不该省的就是这 30 块**。真正该省的是：别买 Ø100（¥96），买 Ø90（¥59）就已经省了 ¥37，效果几乎没差别。

### 所以按这个顺序做

1. **问客服：Ø90 单个多重？**
   - ≈225g → **实心，直接下单**，这是当前最优解
   - 80g 左右 → 空心罩，看第 2 步
   - 不回答/含糊 → 换一家，搜「亚克力实心半球 90mm」，很多店会直接标重量

2. **如果是空心罩**：先别买这家。去搜明确写"**实心**"且标了重量的，¥59~70 区间有货。
   空心罩只在一种情况下买：壁厚 ≥6mm、罩口平整、能接受多做一块封板。

3. **只买 1 个，别买 2 个。** 先确认面型和那家店靠不靠谱，第二件等第一件验收完再说。

### 这一件的验收顺序（到手 10 分钟）

1. **称重** —— 225g 才算对版
2. **灯管测试** —— 斜照球面，看反射的灯管直不直（这是最关键的一步）
3. **贴屏试看** —— 平板/手机显示黑底两只眼，贴在平面上，看眼睛是否"浮"在球心、边缘是否发雾
4. 三项都过 → 再买第二件、再打结构件

> 第 3 步不需要任何结构件：**拿你的微雪板（或任何手机屏）贴在平面上就能看效果**。
> 这一晚上就能知道这钱花没花错，不用等打印。
