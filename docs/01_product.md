# 01 · 产品定义与参考拆解

## 1.1 我们要做的是什么

一个**桌面级、带语音交互的透明球体 AI 伴侣**。用户看到的第一眼不是「一个带屏的音箱」，而是「一颗玻璃球里有一双会看你的眼睛」。

产品情绪定位：**安静、有生命感、不喧哗**。它不是音箱，不是闹钟，是一颗放在桌上的「活物」。

三条不可妥协的体验红线：

| # | 红线 | 判据 |
|---|---|---|
| 1 | 球体必须看起来是**整颗玻璃** | 关灯后除眼睛外不漏光；白天看不见内部结构和屏幕边界 |
| 2 | 眼睛必须**浮在球内**，不能像贴纸 | 侧面 30° 观察，眼睛相对球壳轮廓有位移 |
| 3 | 眼睛的**黑是真空黑** | 用照度计贴球面测暗部，OLED 黑区应 ≤ 环境反射，不能是灰 |

任何一条做不到，这个产品就退化成「亚克力罩子里塞了块屏」。

## 1.2 参考产品拆解（依据用户 37.7s 录屏，592×1280）

录屏内容是抖音账号「程野与路遥」（IP 河南，5.4 万粉，160.5 万赞）的作品合集。逐帧结论：

### 事实清单

| # | 观察到的事实 | 帧位置 | 对设计的含义 |
|---|---|---|---|
| F1 | 主体是一颗**高透球体**，表面有明确的高光/窗影反射 | 2s、13s | 外壳是玻璃或高透亚克力，且**表面必须抛光**，否则没有"玻璃感" |
| F2 | 球内是**一整块深黑面**，黑面几乎铺满球的正投影 | 15s、21s | 内部不是一个小盒子，是**整球黑内胆** |
| F3 | 黑面上有**两只竖胶囊眼**，浅蓝/浅青色 | 15s、21s | 眼是圆角矩形胶囊，不是圆点；色温偏冷（约 8000K 视觉） |
| F4 | 黑面顶部有一条**仿手机状态栏**：WiFi 图标 + 时间（15:09 / 16:19 / 16:29）+ 电池图标，时间随真实时间变化 | 2s、15s、21s | 作者刻意做成"手机里住着一个人"的叙事；时间是真时钟（板载 RTC） |
| F5 | 黑面上方有一道**弧形接缝** | 15s、21s | 内胆（或内胆前后壳）的分界线，被透明球壳折射放大 |
| F6 | 球放在一个**环形/杯状底座**上（2s 可见透明感圆环座），另一些镜头直接放桌面 | 2s、8s | 底座是可选件，但环形托座能显著提升"展品感" |
| F7 | 手持时球约**单手可握**，与手掌宽度接近 | 10s、13s | 外径 90~115mm，取 **Ø110** |
| F8 | 15s 处**球壳被当放大镜用**：把 PCB 放在球后，透过球看板子被放大 | 6s | 作者用过「球透镜」玩法；球壳有一定壁厚或为实心球 |
| F9 | 桌面零件堆里有：**透明半球 + 蓝色环**、金属圆环、圆形屏、各路小板、电池 | 33s | 手工 DIY，非量产模具；蓝环 = 灯环 |
| F10 | 有一个**独立小模块**：小方屏显示两点 + 绿色指示灯，背景蓝光晕，字幕"开心" | 36s | 情绪状态是产品核心功能之一，不只是装饰 |
| F11 | 账号主页写着「**同款：粉丝群（优先进新群）**」 | 27s | 作者有小规模复制销售；我们做**自用复刻**，不与之竞争 |

### 归一化测量（把画面按球径归一）

以 15s 帧为基准：球外轮廓 ≈ 700px（x 130→830），眼睛左 x398–443、右 x545–592，眼高 y510–625。

| 参数 | 归一化值（÷球径） | Ø110 时 |
|---|---|---|
| 眼宽 | 0.064 | 7.0 mm |
| 眼高 | 0.160 | 17.6 mm |
| 眼中心距 | 0.215 | 23.6 mm |
| 状态栏到眼顶 | ≈0.28 | 31 mm |
| 黑面直径 | ≈0.85~0.90 | 94~99 mm |

> 关键推论：**眼高只占球径 16%**，远小于我最初的直觉。所以 1.75" 屏（Ø44.4）在 Ø110 球里 **1:1 直接用就够**，不需要放大透镜。
> 而"黑面 0.85~0.90 球径"这个量级，只有**整球内胆**能做到——用小盒子（Φ48）会让黑面只剩 44%，一眼假。

### 状态栏的位置问题

状态栏在眼顶上方约 31mm，而 1.75" 屏半径只有 22.2mm。也就是说：**参考产品里状态栏和眼睛大概率不在同一块屏上**，或者他用的是更大的屏（3.4" 圆屏 Ø87，或切了一块手机屏）。
我们不做这个取舍——把状态栏放在屏顶、缩小字号，语义保留、尺寸压缩。这是本方案与参考产品的第一处主动偏离。

## 1.3 我们与参考产品的差异（主动选择，不是做不到）

| # | 差异 | 理由 |
|---|---|---|
| D1 | 状态栏压缩到 1.75" 屏内 | 不换大屏，省 ¥400+，避免 LCD 灰底破坏"真空黑" |
| D2 | 内胆做**整球**而非半球罩 | 球壳内壁反射会打到内胆外表面，整球+哑光才能彻底消光 |
| D3 | 球与底座**磁吸 pogo 分离** | 参考产品像是直连；能拿起来把玩是体验分水岭 |
| D4 | 底座上沿加 **RGB 灯环**（16 灯） | F9 里的蓝环说明作者也在用；呼吸/说话律动极大提升"活着"的感觉 |
| D5 | 球体**可拆**（4 颗 M2） | 参考产品是粘死的；我们要能反复折腾 |
| D6 | 屏退后 10mm 制造视差 | 参考产品的屏似乎贴得很近；退后才有"在里面"的错觉 |

## 1.4 不做的事（明确排除）

- ❌ 全息/投影方案（亮度、成本、可靠性全不达标）
- ❌ 实心玻璃球 CNC（一颗 ¥300+，且装不进东西）
- ❌ 眼球机械转动（本项目只做表情，转头留给下一代）
- ❌ 透明 OLED（市面无 Ø80 以上可买样品）
- ❌ 摄像头（隐私红线，且球内没有干净的光路）

## 1.5 验收标准（V1.0）

| 项 | 标准 | 测法 |
|---|---|---|
| 消光 | 暗室开机，眼外无可见亮斑/漏光 | 关灯拍照，直方图暗部 ≤3% |
| 玻璃感 | 正面视区无划痕、无雾度、无异色 | 目视 + 斜 45° 打光 |
| 眼形 | 眼高 17.6±0.5mm（球径的 16%） | 卡尺测量屏幕亮度区 |
| 视差 | 侧移 30° 时眼睛相对球壳轮廓位移 ≥3mm | 固定机位拍照比对 |
| 装配 | 单人 5 分钟内可拆装球体与底座 | 计时 |
| 语音 | 3m 内正常唤醒，回声不啸叫 | 实测 10 次 |
| 续航 | 常亮待机 ≥6h，连续对话 ≥2.5h | 放电测试 |
