# 07 · 装配与工艺

> 顺序不能乱：**先做消光，再装屏；先验光学，再合球。**

## 7.1 工具

| 类 | 清单 |
|---|---|
| 手工具 | 十字螺丝刀 PH0、镊子、卡尺、美纹纸、无尘手套 |
| 打印后处理 | 800/1500/3000 目水砂、抛光膏、羊毛轮（可选电磨） |
| 装配 | UV 胶 + 紫外灯、哑光黑喷漆、植绒纸、EVA 垫、热缩管 |
| 测试 | USB 电流表、手机（拍黑图验漏光）、卷尺 |

## 7.2 装配流程（V1，可拆版）

### Step 1 · 打印件后处理（2h，含干燥）

1. 内胆前壳/后壳/接口环 用 PETG 打印（参数见 03 章 3.9）
2. 去支撑 → 800 目打磨窗口内壁与切平面 → 擦净
3. **哑光黑喷漆**：距离 200mm、薄涂 3 遍（每遍间隔 15min），重点喷外表面与窗口倒角
4. 内表面贴一圈**黑色植绒**（前窗周围 15mm 环带，用双面胶打底）

> 关键：喷漆后必须**完全干透 24h** 再装屏，否则溶剂蒸气会在屏面结雾，永久性白斑。

### Step 2 · 屏/板安装（30min）

1. 板上 8pin 排母焊 8 根 60mm 硅胶线（红黑黑白黄绿蓝灰，按 04 章接线表）
2. 板正面贴 0.5mm 黑色 EVA 环（Ø48 外/Ø44 内），遮住屏边与 FPC
3. 板从内胆后壳塞入，屏面朝前，用 4× M2×6 拧进铜螺母柱
4. 前壳从前方套上，屏对正 Ø47 窗；两壳 3× M2×8 合拢
5. **此时先别合球** → 直接接 5V 点亮，验 Step 3

### Step 3 · 光学验收（30min）

| 检查 | 做法 | 不合格怎么办 |
|---|---|---|
| 漏光 | 暗室点亮全黑，贴球位置拍一张 | 加 EVA、检查 FPC |
| 屏边不可见 | 正视 500mm，屏显示全黑 | 内胆黑度不够 → 补喷/加植绒 |
| 眼睛尺寸 | 显示全亮胶囊，卡尺量 | 改 UI 参数重烧 |
| 双影 | 侧 30° 打台灯 | 内胆外表面没喷哑光 |

### Step 4 · 内胆入球（20min）

1. 下壳半球平放，内胆（已合拢）放进去，屏朝上（+X 方向对应球的前方）
2. 内胆底部 4 个凸台与下壳内壁贴合，微调使屏中心对准球心轴
3. 接口环从球壳外侧套进 Ø56 底孔，UV 胶固定（4 点先点胶定位，再整圈）
4. 8 根线穿出接口环，焊到 pogo 针上，热缩管包覆

### Step 5 · 合球（10min）

1. 上盖半球套上，3 个卡扣对齐
2. 顺时针转 15° 锁死
3. **对缝检查**：45° 侧光下看接缝，宽度应 ≤0.15mm
4. 若超差：拆开，用 3000 目轻磨接缝两侧再合

### Step 6 · 底座（1.5h）

1. 底座打印 → 内腔贴铜箔胶带（可选，屏蔽）→ 装 IP5306、电池（3M 胶固定）、MAX98357、喇叭
2. 喇叭朝下，出声孔贴防尘网
3. 灯环 WS2812 贴进上沿环槽，导光件压上（点胶 4 点）
4. 配重钢环粘在底部，底盖 4× M2 自攻合上，贴 4 个 EVA 胶垫
5. pogo 母座（针朝上）装到底座顶面凸台，磁铁同极性朝上（**先拿磁铁试极性**，装反会推斥）

### Step 7 · 整机联调（1h）

1. 球落到基座：磁吸吸合，pogo 接触，屏亮起
2. 拿起球：断电（或切内置电池）；放回：恢复
3. 语音：3m 距离喊 10 次，成功率 ≥9
4. Wi-Fi：装壳前后 RSSI 对比，衰减 <5dB
5. 功耗：待机 / 对话 / 峰值各测一次

## 7.3 消光工艺（最容易翻车的一步）

| 位置 | 错误做法 | 正确做法 |
|---|---|---|
| 内胆外表面 | 亮面黑打印直接装 | 哑光喷漆 3 薄层，或磨砂后喷 |
| 内胆内表面 | 只喷漆 | 喷漆 + 前窗环带贴植绒（植绒反射率 <1%） |
| 窗口倒角 | 直线切口 | 45°×0.8 倒角 + 涂黑（陷光） |
| 屏边 | 露 FPC | 黑色 EVA 环 + 醋酸胶带包边 |
| 走线孔 | 开在正面 | **只能在背面/底部** |

> 判定标准：暗室开机、屏显示全黑时，把手机贴在球面上拍一张，**直方图暗部不能有 2% 以上的灰度峰**。

## 7.4 粘接工艺（V1.0 精修版）

1. **溶剂选择**：二氯甲烷（快）或氯仿（慢、更透）。用注射器沿接缝毛细渗透。
2. **预对齐**：先干装卡扣定位，用美纹纸做 4 个对齐标记。
3. **渗透**：沿缝每 20mm 点一滴，自然渗入，**不要挤压**（挤压会出气泡）。
4. **固化** 24h（别信"5 分钟"）。
5. **打磨**：800 → 1500 → 3000 目，每次换号要清洗。
6. **抛光**：亚克力抛光膏 + 羊毛轮，中速、少量多次，别烧糊（>60℃ 会发白）。
7. **最终检查**：在强侧光下转一圈，接缝处不能有亮线或雾带。

> 粘死 = 不可维修。建议**先做一次可拆版用 2 周**，确认结构和固件都稳定了，再粘死。

## 7.5 装配检验清单（打印出来逐项打勾）

- [ ] 球壳内外无划痕、无指纹（戴手套操作）
- [ ] 内胆外表面全部哑光，无遗漏亮点
- [ ] 屏面与窗口同轴，四周压边均匀（目视 1.3±0.3mm）
- [ ] 暗室全黑无漏光
- [ ] 眼睛尺寸 17.6±0.5mm
- [ ] 侧 30° 无视差双影
- [ ] 合缝 ≤0.15mm
- [ ] 磁吸吸力手感"咔哒"，无歪斜
- [ ] pogo 8 针全部导通（万用表逐针）
- [ ] 拿起/放回 10 次，无接触不良
- [ ] 灯环 16 灯全亮，颜色一致
- [ ] 喇叭无破音（80% 音量放人声）
- [ ] 3m 唤醒 10 次 ≥9
- [ ] Wi-Fi 衰减 <5dB
- [ ] 待机功耗 ≤1.0W
- [ ] 整机重量 505±30g

## 7.6 常见故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 屏边能看到一圈灰 | UI 背景不是纯黑 / 屏幕亮度太高 | 改 `#000000`，降亮度 |
| 球里有雾 | 喷漆未干透就装配 / 环境湿度大 | 拆开晾 48h，装干燥剂 |
| 眼睛有重影 | 内胆外表面亮面反射 | 补喷哑光 |
| Wi-Fi 掉线 | 碳黑 PETG 内胆 | 换白料重打 |
| 喇叭闷/破音 | 腔体太小 / 出声孔被堵 | 扩腔、开孔 |
| 磁吸吸不住 | 磁铁装反（推斥） | 拆下重装同极朝上 |
| 拿起来就重启 | pogo 断开瞬间掉电 | 加 300mAh 小电池缓冲 |
| 接缝发白 | 打磨没到位/抛光滑石过多 | 重磨重抛 |
